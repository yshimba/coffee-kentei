# コーヒー検定 学習ノート

コーヒーインストラクター検定の個人学習用教材をまとめるサイトです。リポジトリ・サイト全体では級を限定せず、各教材で対象範囲を示します。

- トップページ: https://yshimba.github.io/coffee-kentei/
- 産地別の特徴: https://yshimba.github.io/coffee-kentei/origins/

## 構成

```text
index.html          教材一覧
origins/index.html  産地別の特徴・比較表・暗記カード
.nojekyll           HTMLをそのまま公開
```

## 教材の追加方法

1. テーマ別のフォルダを作り、その中に `index.html` を配置する。
2. トップの `index.html` の教材一覧に、そのフォルダへの相対リンクを追加する。
3. 教材に対象範囲・出典と、教材一覧に戻る `../` リンクを付ける。
4. `main` ブランチに反映するとGitHub Pagesが更新される。

ビルド処理や外部ライブラリは不要です。公開設定は `main` ブランチのルートです。

## 学習記録と資料

暗記カードの記録は利用者のブラウザ内（localStorage）に保存し、サーバーへ送信しません。以前のローカルHTML・別ドメインでの記録は自動移行されません。

公式教本の現物とは未照合の補助教材です。各教材に記載された年度・基準・出典を確認し、試験では受講中の教本・講習を優先してください。

産地地図はNatural Earthのパブリックドメインデータを使用しています。
